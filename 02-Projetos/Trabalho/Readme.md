# 🔧 Chamado Técnico

Sistema web básico para gerenciamento de chamados técnicos.

O projeto foi desenvolvido como atividade prática da disciplina de **Desenvolvimento Front-End**, utilizando HTML5, CSS3 e JavaScript puro.

## 📋 Sobre o projeto

O sistema permite registrar chamados técnicos e visualizar as informações cadastradas.

Cada chamado possui:

* 👤 Funcionário
* 💻 Equipamento
* 🆔 ID
* 📝 Problema
* 📌 Status do chamado

Os chamados são adicionados dinamicamente através do JavaScript.

## 🚀 Funcionalidades

* Cadastro de chamados
* Exibição dos chamados cadastrados
* Identificação automática do número do chamado
* Status inicial como **Recebido**
* Limpeza automática do formulário após o cadastro
* Layout responsivo
* Interface simples e objetiva

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Flexbox

1. Baixe ou clone o repositório.

2. Abra a pasta do projeto.

3. Execute o arquivo:

```text

```

4. O sistema será aberto no navegador.
